# ChopHub — Restaurant & Food Ordering App

A responsive Nigerian restaurant and food ordering frontend built with React and Vite. Customers can browse meals, search and filter the menu, manage a cart, submit a demo order, and contact the restaurant.

## Technologies
- React JS + Vite
- React Router DOM
- JavaScript (ES6+)
- CSS3 (Grid, Flexbox, media queries)
- Lucide React icons
- Local Storage for cart persistence

## Getting started
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in your terminal.

## Production build
Run `npm run build`. The production-ready files will be created in `dist/`.

## Deployment
Deploy the project to Netlify or Vercel. Build command: `npm run build`; publish/output directory: `dist`.

## Notes
This is a frontend demonstration. Checkout displays a demo order confirmation; it does not process payments or send orders to a real restaurant. Replace the sample contact details and connect a backend/payment provider before using it commercially.
